# Project origin

According to the project owner, this project began as a GPT-assisted MVP built from scratch while operating the owner's own signed-in Douyin account. It was expanded iteratively as real workflows were tested.

During development, GitHub projects were reviewed for general ideas, but the owner reports that no repository was adopted as this project's codebase and no known third-party application source was copied into it. The current Git history starts from a later private snapshot and is not evidence of the earliest development steps.

This statement does not fabricate missing history. If later review identifies copied or modified third-party code, its source and license must be added to `THIRD_PARTY_NOTICES.md`, and incompatible or unlicensed material must be removed before redistribution.
